# Little Lemon Reservation App

A cross-platform iOS mobile application built with SwiftUI for restaurant table reservations, developed as part of the Meta iOS Developer Professional Certificate on Coursera.

## Features
- **Locations View**: Browse multiple restaurant locations (Las Vegas, Los Angeles, San Francisco, Nevada)[cite: 8].
- **Reservation Form**: Interactive booking form with real-time field validation (Name, Phone, Email, Party size, and Date Picker).
- **Reservation Details**: View current confirmed booking details with centralized Model state management.

## Tech Stack
- **Language**: Swift / SwiftUI
- **Architecture**: MVVM with Combine (`@ObservableObject`, `@StateObject`, `@EnvironmentObject`)
- **IDE**: Xcode
